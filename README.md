# DevSecOps Automated Security Gate & Policy-as-Code Lab

A university and portfolio project about checking infrastructure changes before they are merged.

**Current status:** planning. No executable Terraform configuration, security workflow, or Rego policy has been verified.

## First presentation milestone

With 5–6 hours per week, build one small S3 Terraform example, demonstrate a Checkov violation and fix locally, and run selected checks on GitHub pull requests. Verify required-check settings and a blocked merge before claiming an enforced gate. OPA/Rego and real Terraform plan evaluation are later extensions. Initial scans do not deploy AWS resources.

## How to work

Read STATUS.md for the next task. Make a small branch, run the relevant check locally, record the actual result in implementation.md, then open a pull request. An insecure example must produce the intended finding; a tool error is not a detected policy violation.

A failed CI job blocks merging only when applicable required-check rules are configured. Passing selected checks does not prove complete security. Earlier detailed plans remain available in Git history.
